# Web Programming 실습 및 과제 저장소 🌐

학교 수업에서 배운 웹 프로그래밍 예제 실습 문제 과 오픈 챌린지(Open Challenge) 과제 수행을 기록하고 관리하는 저장소입니다.

---

## 📁 디렉터리 구조

```text
web/
├── 0903/                 # 9월 3일 수업 실습 예제 (exam1.html ~ exam3.html)
├── 0909/                 # 9월 9일 수업 실습 예제 및 과제
│   ├── openchallenge/    # 오픈 챌린지 과제 수행 폴더
│   └── *.html            # 교재/수업 실습 예제 HTML 파일들
├── 0916/                 # 9월 16일 수업 실습 예제 및 과제
│   ├── chap03/           # 3장 HTML5 시맨틱 태그 및 폼 태그 실습 예제
│   ├── openchallenge/    # 오픈 챌린지 과제 (스마트폰 소개, 설문지)
│   └── report/           # 실습 과제 문제 (버튼, 브라우저 소개, 로그인 폼 등)
├── 0923/                 # 9월 23일 수업 실습 예제 및 과제
│   └── cp/               # 4장 HTML, CSS 실습 예제
│       └── openchallenge/    # 오픈 챌린지 과제 
├── 0930/                 # 9월 30일 수업 실습 예제 및 과제
│   ├── chap/             # 5장 CSS3 배치 및 고급 스타일 실습 예제 (1.html ~ 16.html)
│   ├── openchallenge/    # 오픈 챌린지 과제 폴더
│   ├── index.html        # 개인 이력서 및 자기소개서 웹페이지
│   └── style.css         # 이력서 페이지 커스텀 스타일시트
├── media/                # 이미지, 오디오 등 실습에 사용되는 미디어 리소스
└── README.md             # 프로젝트 소개 및 안내 문서
```

---

## 🛠 사용 기술

- **Language**: HTML5, CSS3, JavaScript
- **Environment**: Web Browser (Chrome, Edge 등)

---

## 🚀 실행 방법

1. 저장소를 클론하거나 다운로드합니다.
2. 실행하고자 하는 주차별 폴더(`0903`, `0909`, `0916`, `0923`, `0930` 등)로 이동합니다.
3. 확인하고 싶은 `.html` 파일을 웹 브라우저로 엽니다 (더블 클릭 또는 브라우저로 드래그 앤 드롭).
