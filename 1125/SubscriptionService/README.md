# SubPulse — 구독 서비스 & 고정지출 시각화 대시보드

매달 빠져나가는 OTT, 음악, AI 툴, 멤버십 등 다양한 구독 서비스를 한눈에 모아보고, **해지 시뮬레이션**과 **결제일 캘린더 알림(`.ics`)** 을 통해 고정지출을 절약할 수 있도록 만든 순수 웹 표준 기반 대시보드입니다.

> 백엔드 서버나 회원가입 없이 브라우저만으로 즉시 입력·시각화·저장·알림 내보내기까지 동작합니다.

---

## 주요 기능

1. **1초 컷 인기 구독 프리셋 & 커스텀 등록**
   - 넷플릭스, 유튜브 프리미엄, 쿠팡와우, Spotify, ChatGPT Plus 등 주요 구독 서비스 10종을 클릭 한 번으로 추가할 수 있으며, `프리셋 등록` / `×` 제거 / `기본 복원`을 지원합니다.
   - `직접 추가하기` 모달에서 **매월/매년 결제 주기**, **내 부담 설정(1/N 인원 분담 또는 직접 금액 입력)**, **구독 시작일 또는 결제일**, **결제 수단**, **한 줄 메모**를 등록할 수 있습니다.

2. **월간/연간 지출 시각화 · 목표 예산 · 결제 진행률**
   - 상단 KPI 카드에서 **이번 달 총 고정지출**, **결제 완료 vs 남은 예정 금액 진행 바**, **월 목표 예산 초과 게이지**, **연간 체감 비유**, **다음 결제 D-Day**를 제공합니다.
   - **Chart.js 도넛 차트**와 **바(Bar) 차트**(해지 시뮬레이션 전후 비교 / 월초·중·말 분포)를 동시에 제공합니다.

3. **해지 시뮬레이션 스위치 (ON / OFF) & 일괄 정리**
   - 각 구독 항목의 스위치를 `OFF`로 전환하면 삭제 없이 절약 효과를 실시간 시뮬레이션하며, 배너에서 `모든 구독 다시 켜기` 또는 `OFF 항목 일괄 해지`가 가능합니다.

4. **검색 · 상태 필터 · 월간 결제일 달력 보기**
   - 서비스명·결제수단·메모 실시간 검색과 상태 필터(`전체 / 사용중 / 시뮬 OFF`)를 지원합니다.
   - `리스트 | 달력` 보기 전환으로 한 달 결제 일정 분포를 달력 UI로 확인할 수 있습니다.

5. **결제일 캘린더 알림(`.ics`) & JSON 백업/복원**
   - 자바스크립트 `Blob API`로 결제 3일 전 알림(`VALARM`)이 포함된 `.ics` 파일을 생성해 다운로드할 수 있습니다.
   - 구독 목록, 커스텀 프리셋, 목표 예산 설정이 `localStorage`에 자동 저장되며, JSON 파일로 통합 백업/복원이 가능합니다.

## 기술 스택

- **Markup / Style**: HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid, 반응형 레이아웃, 다크 모드)
- **Logic & Web API**: Vanilla JavaScript (ES6+), Web Storage API (`localStorage`), `Blob API`, `FileReader API`
- **Visualization**: [Chart.js](https://www.chartjs.org/) (CDN)

## 실행 방법

별도의 설치나 빌드 과정 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 열면 바로 실행됩니다.

> **시연 추천 순서**  
> `샘플 데이터` 클릭 → 상단 KPI 및 도넛 차트 확인 → 원하는 구독 스위치를 `OFF`로 전환해 절약 시뮬레이션 확인 → 캘린더(`.ics`) 아이콘 클릭 및 다크 모드 전환
