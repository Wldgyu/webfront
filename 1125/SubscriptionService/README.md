# SubPulse — 구독 서비스 & 고정지출 시각화 대시보드

매달 빠져나가는 OTT, 음악, AI 툴, 멤버십 등 다양한 구독 서비스를 한눈에 모아보고, **해지 시뮬레이션**과 **결제일 캘린더 알림(`.ics`)** 을 통해 고정지출을 절약할 수 있도록 만든 순수 웹 표준 기반 대시보드입니다.

> 백엔드 서버나 회원가입 없이 브라우저만으로 즉시 입력·시각화·저장·알림 내보내기까지 동작합니다.

---

## 주요 기능

1. **1초 컷 인기 구독 프리셋 & 커스텀 프리셋 관리**
   - 넷플릭스, 유튜브 프리미엄, 쿠팡와우, Spotify, ChatGPT Plus 등 주요 구독 서비스 10종을 클릭 한 번으로 즉시 추가할 수 있습니다.
   - `프리셋 등록` 버튼으로 내가 자주 쓰는 서비스를 1초 컷 목록에 직접 추가하거나 각 항목의 `×` 버튼으로 제거·복원할 수 있습니다.
   - `직접 추가하기` 모달에서 구독 시작일 또는 매월 결제일 기준으로 등록·수정할 수 있으며, 연간 예상액과 다음 결제 D-Day를 실시간 미리보기로 제공합니다.

2. **월간 / 연간 지출 시각화 & 체감 비유**
   - 상단 3단 KPI 카드에서 **월간 총 고정지출**, **연간 환산 예상 지출**, **가장 임박한 다음 결제 D-Day**를 한눈에 확인할 수 있습니다.
   - 연간 지출 규모에 따라 직관적인 체감 비유(치킨 / 에어팟 프로 / 최신 아이패드 / 해외여행 왕복 항공권)를 자동으로 표시합니다.
   - **Chart.js 도넛 차트**와 카테고리별 비중 바로 지출 구조를 한눈에 파악할 수 있으며, 구독 목록에서 결제 임박순 정렬 및 D-Day 배지를 바로 확인할 수 있습니다.

3. **해지 시뮬레이션 스위치 (ON / OFF)**
   - 각 구독 항목의 스위치를 `OFF`로 전환하면 항목을 삭제하지 않고도 **"월 OOO원 · 연 OOO원 절약 중"** 효과를 상단 KPI와 차트에 실시간 반영해 볼 수 있습니다.

4. **결제일 캘린더 알림 내보내기 (`.ics`)**
   - 자바스크립트 `Blob API`만으로 RFC 5545 표준 iCalendar(`.ics`) 파일을 생성해 다운로드합니다.
   - Apple 캘린더, Google 캘린더, 삼성 캘린더에 등록하면 **결제 3일 전 해지 검토 알림(`VALARM`)** 이 자동으로 설정됩니다.

5. **데이터 자동 저장 및 백업 · 시연 편의 기능**
   - `localStorage` 자동 저장으로 새로고침 후에도 데이터가 유지됩니다.
   - `JSON 백업 / 복원` 기능으로 기기 간 데이터 이동이 가능합니다.
   - `샘플 데이터` 버튼 클릭 한 번으로 발표 시연용 7개 구독 데이터를 즉시 채울 수 있으며, 라이트/다크 모드를 지원합니다.

## 기술 스택

- **Markup / Style**: HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid, 반응형 레이아웃, 다크 모드)
- **Logic & Web API**: Vanilla JavaScript (ES6+), Web Storage API (`localStorage`), `Blob API`, `FileReader API`
- **Visualization**: [Chart.js](https://www.chartjs.org/) (CDN)

```text
SubscriptionService/
├── index.html   # 대시보드 마크업 및 모달 구조
├── style.css    # 라이트/다크 테마 토큰 및 반응형 스타일
├── app.js       # 상태 관리, KPI/D-Day 계산, Chart.js 연동, .ics/JSON 입출력

```

## 실행 방법

별도의 설치나 빌드 과정 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 열면 바로 실행됩니다.

> **시연 추천 순서**  
> `샘플 데이터` 클릭 → 상단 KPI 및 도넛 차트 확인 → 원하는 구독 스위치를 `OFF`로 전환해 절약 시뮬레이션 확인 → 캘린더(`.ics`) 아이콘 클릭 및 다크 모드 전환
